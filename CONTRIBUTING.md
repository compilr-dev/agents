# Contributing to @compilr-dev/agents

Thanks for your interest in contributing to the compilr.dev agents library.

## Reporting Issues

Found a bug or have a feature idea? [Open an issue](https://github.com/compilr-dev/agents/issues/new/choose) using one of our templates:

- **Bug Report** -- Include your package version, the LLM provider, and a minimal code snippet that reproduces the issue.
- **Feature Request** -- Describe what you're building and how the library could help.

Good bug reports include:
- A minimal TypeScript snippet that reproduces the problem
- The provider you're using (Claude, OpenAI, Gemini, Ollama, etc.)
- Your environment (OS, Node.js version)
- The full error message or unexpected output

## Source Code

This repository is a **public mirror** for issue tracking and documentation. The source code is developed in a private repository. We publish compiled packages to npm.

**Pull requests are not currently accepted.** If you have a code contribution in mind, please open an issue first to discuss the approach.
